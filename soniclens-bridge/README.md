# Soniclens Bridge

Soniclens Bridge is an iOS/iPadOS/macOS app that connects to the SonicLens server over LAN, showcases dashboard capabilities, and provides a music-library experience inspired by Apple Music.

## Targets
- iPadOS 17+
- macOS 14+ (Catalyst)

## App Structure (High-Level)
- Tabs
  - Home (Dashboard)
  - Library
- Global Mini Player above the tab bar
- Fullscreen player with lyrics and AI insights
