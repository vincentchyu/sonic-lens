# 首页热门艺术家头像映射闭环

## 背景

首页“热门艺术家”原先只展示首字母圆牌，没有艺术家头像的正式数据闭环。为了支持 Pink Floyd 的联调图片和后续艺术家资料生态，需要把头像映射从统计事实表里拆出来。

## 这次改动

- 后端新增 `artist_profile` 资料表，按艺术家名和归一化键保存头像信息。
- `top-artists/plays` 和 `top-artists/tracks` 响应补齐 `avatar_url`、`avatar_object_key`、`avatar_mime`。
- Bridge 三端的热门艺术家卡片优先显示对象存储头像，失败时继续用首字母圆形兜底。

## 结果

- Pink Floyd 的测试头像可直接挂到首页热门艺术家位。
- 统计事实和资料映射分离，后续做艺术家详情或更多头像资产时可以继续复用这条链路。
